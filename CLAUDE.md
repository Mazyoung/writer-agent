# Writer-Agent Project Instructions

For every engineering task, read `docs/claude.md` first. Current source code and current tests are the highest sources of truth; documentation must not override verified runtime behavior.

For any E07 or LangGraph workflow change, also read `docs/E07_LANGGRAPH_MIGRATION_GUIDE.md` before editing.

## Python Environment

Use the Conda environment named `writer` for all Python commands in this project. On the current Windows workspace, invoke its interpreter directly as `E:\code\miniconda\envs\writer\python.exe` when practical. Do not use the repository-local `venv`, which is not the project runtime environment.
