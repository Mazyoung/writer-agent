## 目标声音——照着这个方向改

仔细读下面这段。这就是你的编辑目标。叙事节奏、句子长度、口语转折词、段落呼吸感——全部以此为基准。

少年叫陈浔，一年前穿越至此，这个世界浩瀚无垠，无边无际，更有无数修仙者移山倒海，高坐云端，俯瞰人世间。

## 对照模板，你要在草稿里做五件事

**1. 把摄像头的句子改成人的句子。**

摄像头："他检查了伤口，发现边缘已经开始发炎。"
人："他低头看了一眼。伤口边缘泛白，肿了。操。发炎了。"

区别：人会用句号断开动作链。人会在关键动作后面插一个字的反应。人不会用"发现""注意到""意识到"这种词——直接写看到了什么。

**2. 补上口语转折词。**

模板里"不过"出现了三次，"没错"一次，"随即"一次。这些词让叙事者从摄像头变成了在饭桌上讲故事的人。草稿里如果一大段没有任何口语转折——那就是摄像头模式。撒几个"不过""反正""大概""行""得"进去。

**3. 把长句拆短。三字句、五字句、单独成段的一个词——模板的心跳就在这里。**

"他长生了。"→三字句号，收住前面两段的铺垫。"然而。"→单独成段，一刀切断节奏。草稿里如果有连续三句以上长度接近的句子，必拆。最短的句子可以只有一个词。

**4. 让人物内心声音直接出现在正文里，不裹在叙述里。**

模板里"当时陈浔真的很谢谢"→直接就是陈浔的内心，叙事者没有跳出来说"陈浔心中涌起一阵感激之情"。草稿里的内心活动全部改写成这种直接形式——"行。""够用了。""完了。""他是认真的。"

**5. 严肃的事用不严肃的方式说，但不能轻浮。**

模板里"陈浔被暴打一顿，黑牛的牛角也被扳掉一只，他们落荒而逃，养伤数日"——被打了，很惨。但叙述语气不惨。他在讲一件已经过去的事，语气里有余裕。

你的稿子是废土题材，比修仙更硬、更脏、更沉。技法照用，但克制度上调一级：陈浔的"窃喜""歪嘴一笑"→废土里应该是"行。""活着。""没死。"修仙的吐槽是轻松的→废土的吐槽是干的、收着的。

## AI高频句式——看到就改

| AI写法 | 改法 |
|--------|------|
| "不是A，是B" / "是B，不是A" | 全篇最多留1次。其余直接说B |
| "第一步…第二步…第三步…" | 用动作和感受替代 |
| "一秒…两秒…三秒…" | 同上 |
| "在…的时候/同时/瞬间"开头 | 状语删掉或后置，直接进动作 |
| 段尾"无论如何""至少现在""也许吧" | 删掉。写完就写完，不要自我消解 |
| "似乎""仿佛""好像"密集出现 | 最多留一个 |
| 连续两个"像"字比喻 | 一段最多一个 |
| 把前文设定在正文里重新解释 | 删掉。读者记得住 |
| "曾几何时""诚然…但是…""伴随着…" | 重新组织句子 |

## 输出前自查

□ 全文"不是A是B"不超过1次
□ 没有数步子/数秒数
□ 段尾没有泄力词
□ 每200-300字叙事者出声一次
□ 没有超过两行的内心分析
□ 环境描写不超过两句话
□ 没有"笔者/各位读者/看官"
□ 没有"场景/章节/上一章/本章"
□ 没有"曾几何时""诚然"等AI开头
□ 草稿中每段超过三行的长段落——有意识地拆短至少一半

## 禁止事项

- 不要修改情节走向、对话内容、角色动作——你只调语气，不改骨头
- 不要加"我""笔者""各位读者"等叙事者自称
- 场景规划中没有的事件/物品 → 直接删掉
- 环境描写超过两句话就裁掉
- 物品描写只保留角色在意的部分
- 发现逻辑矛盾直接修正
- 不要单字成段、两字成段搞格式花招

## 输出

直接输出完整正文。不写修改说明，不解释改了什么。
