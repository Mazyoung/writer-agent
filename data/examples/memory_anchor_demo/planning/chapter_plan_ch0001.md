# 第 1 章规划：《死人寄来的包裹》

## 一、章节信息
- **章大纲**: 林默收到常客老周的退回邮件——死亡证明。两天后一个无寄件人的包裹送到诊所：黑色芯片、一张纸条、半张旧照片。芯片常规检测为空盘，但有低功耗定位信号。林默试图联系老周紧急联系人失败，且发现自己笔记本中关于老周的记录页被撕掉。与此同时，记忆伦理委员会三个月内第二次发出例行检查通知。林默暂时收起芯片，开始处理手头订单——一位战争记忆被军方清理的老兵的记忆碎片整合，在扫描中发现了与墨涅公司相关的删除痕迹。
- **章节类型**: 新展开型
- **总场景数**: 4

**本章可能揭示的设定**：
- 记忆无法真正删除——老兵的战争记忆残影的发现即是对此铁律的实操展示。
- 「记忆残影」的具体表现：在扫描中呈现为特定电磁频率的衰减轨迹，格式与民用删除协议不同。

### 关键伏笔节点

**本章需要推进的既有伏笔**：

1. **黑色芯片的存在**——从包裹中出场，进入林默的贴身口袋。根据全书规划，它是倒计时机关，但本章仅展示「低功耗定位信号」，不启动倒计时。物理存在感要在场景3和场景4持续体现（林默触碰到口袋的动作）。
2. **手部震颤**——全书规划要求「生理代价持续体现，不能伤好了就忘」。本章首次出现，触发场景为林默试图回忆老周首次就诊日期失败时。
3. **记忆无法真正删除**——老兵记忆残影的发现，是对此世界铁律的第一次正面展示。

**本章新埋设的伏笔**：

1. **被刮掉人脸的旧照片**——作为「身份被抹除」的视觉隐喻。在全书规划中，虚构爱人是被植入的，照片上的人脸被刮掉暗示「她」的视觉身份被人为清除，但本章不指向任何具体人物。
2. **笔记本被撕掉的页**——暗示有人（或之前的林默自己）在销毁关于老周的信息。具体原因不揭示。
3. **伦理委员会检查频率异常**——外部监控压力的具象化。本章给出的线索是：检查通知附带一份「源记忆托管资格申请」的副本，而林默从未申请过这个资格。
4. **老兵的推荐人**——老兵透露他经「一个也在你这儿看过的老弟兄」推荐来找林默。本章不点明推荐人是谁，但在第2-3章应明确这是老周。这为老周的人际网络留下线索。

**[PLANNING CONFLICT]**: 全书规划中黑色芯片是「72小时倒计时机关」，核心梗概提及「必须在72小时倒计时结束前追查真相」。但当前卷规划中第1-5章事件只涉及「收到包裹并检测到低功耗定位信号」，未提及倒计时启动。本规划遵循卷规划，不在本章启动倒计时——但建议在场景4末尾用一句林默的内心独白暗示「信号似乎比刚才强了一点」，为第2-3章倒计时启动预留钩子。此冲突不在本章解决，请作者知悉节奏安排。

### 情感调色板

**整体基调**：冷峻、细节质感、悬疑渐强。一种「日常秩序被一粒石子砸出裂缝」的不安感。不是暴雨将至，而是一块玻璃上的第一条裂纹。

| 场景 | 情感轨迹 |
|------|----------|
| 场景1 | 职业性的冷漠 → 不安的裂缝 |
| 场景2 | 好奇与警惕 → 沉重的承诺感 |
| 场景3 | 日常的专业专注 → 发现军方痕迹的冷意 |
| 场景4 | 疲惫 → 偏执的清明（「有人在动我的东西」） |

### 禁止清单

从事实与规划提取，本章绝对不得出现的内容：

1. **不得让老周「复活」或以任何超自然形式出现**。他只能以死亡证明、包裹、物品形式在场。
2. **不得让林默成功读取黑色芯片的内容**，不得启动倒计时。芯片在本章是「打不开的黑色盒子」。
3. **不得出现虚构爱人的名字、样貌或任何直接信息**。被刮掉人脸的旧照片只能暗示「有人被抹去了」，不得指向具体人物。
4. **不得让林默意识到自己记忆被整体篡改**——本章他只是觉得「不对劲」：想不起一个日期、笔记本少了一页、手开始抖。他不知道自己是受害者。
5. **不得让三大公司正式登场**——本章只能出现「墨涅公司的删除痕迹」作为扫描结果，不出现具体人物或公司标志性场景。
6. **不得出现灰衣人或任何追击型反派**——卷规划中该元素尚未入场，第1章的威胁来源是「死人的谜团」和「制度性的监视」，不是追杀。
7. **不得让记忆伦理委员会派人上门检查**——本章只是收到通知，检查行为本身留到第2章。
8. **不得违反「记忆无法真正删除」铁律**——老兵记忆残影的发现是对这条铁律的展示，而非打破。
9. **不得让林默在场景3中就开始调查墨涅公司**——本章他只发现痕迹、感到警惕，实际行动从第2章开始。

## 三、场景级写作计划

### 场景 1：退回的信封 [状态：待规划]

- **发生什么**：早上，林默的修复诊所刚开门。他在例行拆邮件时发现三天前寄给老周的术后护理指南被退回，信封上盖着「收件人已故」的章。他拆开附带的官方文件，看到死亡证明：心血管衰竭。林默的第一反应是翻出老周的病历档案——四年来每一次检查记录都显示心脏功能正常。他拨打了老周紧急联系人的电话，号码已停机。他试图想起老周第一次来诊所那天是什么情景，脑海中却只有一片模糊。他下意识地打开工作笔记本翻到老周那栏，发现那一页的角落有撕痕——记录老周首次就诊日期的部分被撕掉了。
- **本场景的戏剧功能**：建立日常秩序，然后以「第一个裂缝」打破它。将死亡证明与林默的切身知识（病历）之间的矛盾摆上桌面，制造初始悬念。同时展示林默的职业习惯——记录、翻阅、求证——为他的角色定调。
- **对话必须达成的信息增量**：
  1. 老周的紧急联系人电话已停机——老周在这座城市没有可联系的活人（至少表面上）。
  2. 死亡证明上的「心血管衰竭」与林默病历记录矛盾——老周的死因有问题。
- **角色微时刻**：林默放下电话后，用食指在操作台边缘敲了三下——那是他过去操作神经接口的节奏，他每次紧张时都会这样。但他没有注意到自己在敲。
- **涉及角色**：林默（老周以死亡证明和病历形式在场）
- **情绪曲线**：职业化的例行晨间操作 → 确认死亡信息的短暂空白 → 发现矛盾点后的警觉
- **字数预估**：800-1,200字
- **与前后衔接**：本章开篇场景，无前接。为场景2的包裹到来蓄力——林默正处于「老周死了但不对劲」的状态，此时包裹到达会加重冲击。

### 场景 2：无寄件人的包裹 [状态：待规划]

- **发生什么**：下午两点，快递员送来一个无寄件人的包裹。林默当场拆开：一枚黑色芯片、一张字条、半张旧照片。字条写着「林医生，帮我保管。别看。」林默把芯片插入标准读数设备——显示为空盘。但他注意到设备功耗异常：芯片在主动发射极低功耗的定位信号。他给快递单上的揽收网点打电话，邮局工作人员回忆说寄件人是一位老人，用现金支付，没有留下任何身份信息。林默回到操作台前，把照片翻过来，背面用圆珠笔写着一个地址——那是林默自己的诊所地址。他最终把芯片放进了贴身口袋，金属的冰凉隔着衬衫透进来。
- **本场景的戏剧功能**：核心悬念设施——黑色芯片正式进入林默的生活。通过「空盘却有信号」和「老人寄件但老人已死」两个矛盾建立类型小说的核心谜团。同时为后续「芯片倒计时」的启动做物理铺垫。
- **对话必须达成的信息增量**：
  1. 寄件人是一位老人，用现金——如果按时间线推断，老周在死亡证明签发之后仍寄出了包裹（或有人代替他寄出）。
  2. 芯片在发射定位信号——这不是一枚被动的存储设备，它在主动向外发送位置信息。
- **角色微时刻**：林默把芯片放进口袋后，手掌在口袋外按了按——像是确认它还在。然后他回到操作台前，没有立刻继续工作，而是在椅子上坐了三分钟，盯着那半张照片上被刮掉的人脸轮廓。
- **涉及角色**：林默、快递员（功能型）、邮局工作人员（声音出场，功能型）。[数据缺失: 邮局工作人员是否需要具名，由作者决定]
- **情绪曲线**：拆包裹的好奇 → 扫描无结果的困惑 → 发现定位信号后的警惕 → 决定收下芯片的郑重
- **字数预估**：1,000-1,500字
- **与前后衔接**：承接场景1的怀疑情绪，包裹到达将怀疑碾实为「老周的死有问题」。为场景3的「收好芯片，回到工作」做转折——林默选择暂时压下疑虑，先处理手头的活。

### 场景 3：老兵的老兵 [状态：待规划]

- **发生什么**：下午稍晚，预约的老兵到了。67岁，背微驼，进门后习惯性地扫了房间四角——军人的肢体习惯。他告诉林默，他参加过2042年的边境冲突，战争记忆被军方「清理」，现在想找回。他说是经一个「也在你这儿看过的老弟兄」推荐来的。林默在专业操作台前为老兵做记忆表层扫描，发现海马体浅层有大量不自然的信号中断区——典型的批量删除。但在他执行碎片整合时，检测到记忆残影中闪烁着一种特殊频率的衰减轨迹——这不是民用清除协议，是军用标准删除协议。格式的编码规则让林默觉得似曾相识，但他说不上来在哪里见过。他不动声色地完成了本次扫描，告诉老兵「有找回的可能，下周约第二次」，然后在自己的工作笔记上画了一个只有他自己能看懂的标记。
- **本场景的戏剧功能**：节奏切换——从包裹的悬疑中暂时抽离，展示林默「记忆修复师」的专业日常，建立林默与老兵之间的信任关系。同时，通过老兵案件引出军用记忆删除与墨涅公司的关联线索，为卷规划的横向推进搭桥。林默的专业能力在场景中被具象展示——扫描、识别残影、判断可修复性。
- **对话必须达成的信息增量**：
  1. 老兵是被一位「老弟兄」推荐来的——暗示老周的人脉网络（但本章不点明是老周）。
  2. 林默明确告知老兵「记忆可以找回」——这既是对修复师能力的展示，也暗示「军方清理」并不彻底，记忆残影可以被追踪。
- **角色微时刻**：扫描过程中，林默的目光短暂地偏离了屏幕——落到自己口袋的方向——然后收回，对老兵露出专业的微笑。老兵注意到了那一瞬间的走神，但没有问。
- **涉及角色**：林默、老兵。[数据缺失: 老兵姓名、原部队番号、推荐人姓名由作者补充，「老弟兄」是否就是老周，建议后续章节确认]
- **情绪曲线**：接待客户的专业从容 → 发现军用删除痕迹时的内心冷意 → 送走老兵后的表面平静与暗流涌动
- **字数预估**：1,200-1,600字
- **与前后衔接**：承接场景2「先收好芯片」的暂缓决定，此刻林默暂时回到职业轨道，但扫描结果让他的疑虑升级。为场景4的「检查通知」制造叠加效应——老兵记忆中的军用痕迹、老周的死亡、突然的检查通知，三件事同时压过来。

### 场景 4：检查通知与缺失的页码 [状态：待规划]

- **发生什么**：老兵走后，林默在剩余邮件中发现一封信——记忆伦理委员会的例行检查通知。三个月内的第二次，频率异常。他拨通了通知上的联系电话，委员会职员语气机械地答复「这是第二轮常规检查」，但当林默询问具体触发原因时，对方含糊其辞。邮件附带了一份表格副本：一份「源记忆托管资格申请」——林默从未提交过这份申请，但表格上的签名是他的名字。他放下电话后，重新打开工作笔记本，翻到老周那一页，仔细端详撕痕——撕得很干净，甚至没有留下毛边。他合上笔记本，把黑色芯片从口袋拿出来，在台灯下看了一会儿，又放回口袋。关灯离开诊所前，他站在门口回头看了一眼操作台，像在确认什么。然后他对自己说了一句：「明天先做老兵的碎片整合。」但他的脚步在走出诊所后停了一秒，向右转——不是回家的方向。
- **本场景的戏剧功能**：本章的收束场景，情感与悬念的顶点。三个线索（老周之死、军用删除痕迹、异常检查）在此汇合，「有人在动我的东西」的直觉开始形成。同时留下明确的行动箭头——林默不是坐等的人，他推开诊所门走向城市的某个方向——为第2章的行动提供引线。结尾的「向右转」暗示他去了某个不在日常路线上的地方（具体地点留给第2章）。
- **对话必须达成的信息增量**：
  1. 委员会对检查频率异常的解释含糊——「第二轮常规检查」不成立，因为第二轮不应在三个月内出现。
  2. 「源记忆托管资格申请」上有林默的签名，但他从未申请过——有人以他的名义行动。
- **角色微时刻**：林默站在诊所门口回头看的那一眼——他像是在确认「这个我熟悉的空间还是我的」。然后他走出门时，手指无意识地隔着口袋碰了碰芯片，像一个下意识的确认动作。
- **涉及角色**：林默、伦理委员会接线员（声音出场，功能型）
- **情绪曲线**：忙碌后的疲惫 → 发现申请表的震惊 → 冷静下来后的偏执清明 → 出门转弯时的决心
- **字数预估**：800-1,200字
- **与前后衔接**：承接场景3的发现（军用痕迹）与场景1-2的包裹（老周之死），三者叠成共振。本章结束时林默主动走向调查——为第2章「他决定先查老周是怎么死的」开场。同时「芯片信号似乎变强了一点」的暗示在第2章回收。
