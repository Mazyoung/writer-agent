# 第四章 Chapter Plan

## 一、本章概览

**章目标**：纪燃在第三章发现的 B3-17 旧管线档案与手写便签基础上，通过回到北三动力站现场核验、与宋锻的有限交换，把"七年前封闭事件"从纸面档案推进为**仍然活动着的异常**，并首次将这条线与师傅焦岩的失踪并到一起。封闭事件的具体原因本章不揭晓，只完成因果链的下一环：**B3-17 不是一条死线，而是被人为反复处理过、至今仍有活着的东西在线路深处的管段。**

**时间线**：承接第三章当天（第1章深夜 → 第2章清晨 → 第3章上午九点 → 第四章同日午后至傍晚）。

**地点**：维修站值班室 → 北三动力站检修区深处 → 维修站第七小队工具间 → 纪燃住处/宿舍。

**出场角色**：纪燃（主视角）、宋锻。

**明确不登场**：温弦（第5章登场）、沈烬（第6章）、董锈（第7章）、铁鸦（第8章）、罗九弦（第9章）。本章不可让上述任何角色以正式身份出现，最多作为背景压力提及"管治会"而未具名。

**规划一致性检查**：本章推进量在 Volume Plan「阶段一/阶段二」之间，不突破闻诉、不触碰察印、不揭开焦岩下落、不解释故障之眼来源、不解开 B3-17 封存真相，与 Book Plan 战略约束核对无冲突。

## 四、场景规划（总场景数 3）

### 场景 1：午前（地点：维修站值班室；时间：午后，已过午前期限）

**场景目标**：解决第二章遗留的"是否恢复供能结论"悬案；给纪燃一个合法重返北三动力站的理由；由宋锻之口投下"焦岩也查过这一片"的第一块石头。

**节拍**：

1. 纪燃从后楼档案室回到维修站主体，经过值班室时意识到午前已过。他手中夹着档案袋（便签已装在里面），手机里有拍下的旧管网图。第2章维修站要求他在午前给出"是否恢复供能"的结论——他没有按时提交。

2. 宋锻在值班室里，看见纪燃，问结论。没有质问的语气，但从眼神打量他。纪燃斟酌后给出答复，措辞类似：**"压力没有再出现异常。检测仪还没修好，我明天复测一次再下结论。目前不建议恢复供能。"** 这个答复既没有撒谎，也没有说出全部实情——他在记录中仍然不写听针里的三下敲击与螺栓三声脆响的呼应（延续第二章的行为）。

3. 宋锻没有追问，把那叠报修单最上面一张递给他："北三动力站东侧回水阀渗漏，下午跑一趟。"——这给了纪燃一个合法进入该区域的借口。纪燃扫了一眼报修单：上面只有常见的设备故障描述，没有任何关于北墙、黑色管道、阀门的记录（与第一章报修单的空缺一致）。他意识到：所有经过他手的正式文件都在回避那个阀门。

4. 纪燃转身要离开时，宋锻在他身后补了一句，说得很轻、像是随口："你师父以前也爱钻那片的老档案。你比他运气好，至少档案还在。"说完就摆手让他走，不再解释。宋锻这句话信息量：焦岩生前也在查北三动力站相关的老档案；"至少档案还在"暗示宋锻知道这批档案险被清理或曾被翻动。

5. 纪燃走出值班室，走在去北三动力站的路上，内心把宋锻的话与自己的发现放回同一个问题里：第七小队以前由焦岩负责维护的区域、焦岩失踪、北三动力站北墙的怪阀门、七年前被封闭的 B3-17——他暂时还无法把这些画成一条线，但"师傅也在查"已经在他心里落地。

**场景 1 落点**：纪燃夹着报修单，往北三动力站方向走。他低头看手机里拍下的旧管网图，B3-17 的铅笔线延伸出图纸边缘。他还不知道宋锻嘴里"焦岩留下的东西"其实还在维修站里锁着。

---

### 场景 2：北墙（地点：北三动力站检修区深处·黑色阀门；时间：下午）

**场景目标**：把 B3-17 的档案知识带回现场验证；确认两件事实——螺栓曾被反复取下（纪燃不是第一个），以及异响至今仍在；第一次隐约捕捉到管线深处的"非机械"声响（闻诉突破的前置铺垫，不作正式突破）。

**场景必需状态（Writer 执行前须知）**：
- 黑色阀门仍封在检修区深处，警示带原样未被碰动；阀门底部原本卡着黑色螺栓的位置现在空着，螺栓在纪燃工具箱内侧小格里。
- 检测仪仍黑屏，纪燃只用黄铜听针。
- 纪燃随身带着装便签的文件袋。

**节拍**：

1. 简写处理东侧回水阀渗漏的报修：拧紧填料压盖、换密封垫，完成日常活儿。这一段两三句带过，作用是确立"他是称职维修工"。

2. 绕到检修区深处，黑色阀门仍在。警示带原样。纪燃蹲在阀门底部，用手电照螺栓原本卡住的位置。卡槽空着，内壁贴近看，有几道细浅的旧划痕，深浅不一、氧化程度不同——只有被反复装上、取下多次才会留下这种痕迹。他想起那枚没有锈迹、没有厂家标记的黑色螺栓，确认**自己不是第一个把它取下的人**。在他之前，有人取下过、又装回去过，重复不止一次。

3. 他从文件袋里展开便签，逐字对照现场："北线三次异响。"——他刚才还没重听，但第二章听到的三下敲击就在记忆里；"仪表无异常。"——他的检测仪坏了，七年前写下这句话的人用仪表也没有发现异常；"螺栓已取下。"——空着的卡槽。他得出一个推论：**写下便签的人，当时正打算做他现在可能做的事——而那道划掉的警告"不要打开末端阀"，意味着有人阻止过他，或者他自己最终放弃了。** 便签没有写完结局。

4. 他拿出听针抵在阀门外壳（复用第二章的声学细节：三下、停顿、再三下，从北侧地下贴近）。这一次他多坚持了十几秒，在低鸣底下捕捉到一丝极轻的、不规则的、像什么东西在金属深处慢慢换气的声音——他无法确定是管线里传来的，还是自己的耳鸣。耳朵确实在响。这不应写到书面记录里。

5. 离开前，他在管道进入墙面的根部注意到一个新的细节：墙皮上有一道很细的新裂纹，从管道根部向上蔓延，像是管道"动过"留下的痕迹。他拿出手机拍下裂纹。同时他感到握听针的右手手指有一瞬间发僵，松开后才恢复；耳朵里的鸣响比来时清晰了一截。

6. 场景 2 结尾的落点：他离开检修区，确认警示带没被自己碰乱。外面没有声音了。他低声重复了一遍便签第一行："北线三次异响。"——他现在确定：写便签的人记录的就是他此刻听见的东西。那不是七年前的一页旧纸，而是**现在、仍然、正在发生的事**。

**场景 2 写作要点**：
- 全程无战斗、无暴力、无醒骸。异常只以声音、震动、裂纹的形式存在。
- 故障之眼的首次轻微表现（如果作者选择加入）：纪燃在低头看卡槽旧划痕时，视线边缘有极淡的光痕浮在划痕表面，眨眼即散，他自己归因为疲劳。此点以不抢戏为限，只写一句，写不写由执行作者视节奏决定。
- 不要在新裂纹上做解释性判断，纪燃不能得出"管线在生长/在动"的结论，只留下疑虑。

### 场景 3：盒子（地点：维修站第七小队工具间 → 纪燃住处/宿舍；时间：傍晚）

**场景目标**：完成本章的信息闭环——B3-17 与焦岩失踪并线；纪燃获得焦岩的一件遗留物（旧检修日志）作为下一阶段调查的实体依托；确立下一步行动方向（回到档案室挪铁柜）。

**节拍**：

1. 纪燃完成下午的报修回到维修站。宋锻把他叫到没人的工具间，关上门，没有绕弯子。宋锻问：你今天钻档案室，查到什么了？——不是盘问，是确认。

2. 纪燃衡量后，只说出部分：北三动力站北墙那片，查出一条停用了七年的旧线。停运记录只有三页，第三页本该附着的封堵施工记录只剩一个空白的目录编号；新版管网图上，整条线都已经不存在了——像是被人从图纸上抹掉的。**他没有提那张便签、没有提拿到的黑色螺栓，也没有提铁皮柜后的三下轻响和那道黑色痕迹。这几样他对谁都不说，包括宋锻。**（便签原文与 B3-17 编号均不出口，宋锻的知情上限由此从严维持。）

3. 宋锻听完，脸色沉下去，沉默了一会儿，说：焦岩失踪以前，也翻过这一片的东西，进过北三动力站东面的旧厂区好几次。焦岩当时跟他说过一句话，他当时没听懂，也没细问——**"北面那段线，怕是没断干净。"** 宋锻说完，补了一句：后来焦岩就失踪了。

4. 宋锻从工具柜底层取出一只旧铁盒，说这是焦岩留在七队的东西：他人失踪以后，工具都留队里，就这个单独锁着。宋锻一直没打开，现在交给纪燃："你跟他一个路子。给你，比我一个人留着有用。"盒子锁扣已锈坏，宋锻没有打开的意思，补了一句：**"回去再看。"** 纪燃接过来，掂了掂分量，没有当场打开。（盒内内容不在宋锻面前展开，留到节拍 6。）

5. 纪燃问：还有别人知道这个盒子吗？宋锻说焦岩失踪后管治会问过话、也翻过他的工具，但没找到这个盒子——"他藏得深。"宋锻警告纪燃：这事不能再让管治会知道，也不能一个人下到旧厂区那边去，"你查出什么，先告诉我。别跟你师父似的一个人扛。"——这是宋锻在本书中保护性压制的松动与信任的落地。

6. 章尾落点：纪燃回到自己的住处/宿舍，把今天的东西铺开：便签、翻拍的旧管网图、下午拍的裂纹照片——黑色螺栓仍在工具箱内侧小格里，没有取出。他最后打开那只旧铁盒：里面是一本旧检修日志和几页散记，日期集中在焦岩失踪前一周，路线记录多次指向北三动力站东侧、旧厂区方向。其中一页只写了一行字，笔画重得几乎划破纸：**"是活的。"** 日志里没有 B3-17 的编号、没有旧焦厂、没有便签——只有这一句。他合上本子时，耳朵里的低鸣还在响。他把听针插回工具箱时，手指伸向内侧小格——**在黑色螺栓上方停住，又收了回来。他依然没有碰它。** 结尾的行动决定：明天一早，他要再去一趟档案室，把那台铁皮柜挪开，看看那道从墙缝延伸到柜下的黑色痕迹，到底通到哪儿。

**场景 3 写作要点**：
- 宋锻全程不知道 B3-17 编号、不知道便签存在、不知道黑色螺栓、不知道铁柜痕迹。他的台词只建立在他自己知道的方向性信息上（"北面那段线""旧厂区"）。
- 铁盒在宋锻面前只以"旧铁盒、锁扣锈坏、他一直没打开"的外观存在；盒内内容（检修日志、"是活的。"）必须在纪燃独处时出现。
