# 第3章 Fact Digest

## Atomic Facts

- [P0002-P0003] 纪燃没有立刻回北三动力站，上午九点先去了维修站后楼的档案室。
- [P0004] 北三动力站建成较早，很多资料未进入电子系统，旧设备改造、管线封堵和历年检修记录保存在维修站后楼档案室的一排铁皮柜里。
- [P0005-P0006] 纪燃查找的是北侧地下管线；值班记录写明那条管线七年前已经停用。
- [P0008-P0015] 纪燃找出的七年前停运记录只有三页：第一页是管线编号和位置，第二页停运原因是“设备老化，功能并入新系统”，第三页本应附有封堵施工记录，却只有一个空白目录编号，没有附件。
- [P0016-P0023] 在更早的总管网图上，北三动力站地下有废弃的蒸汽和回水支线从主站向外延伸，其中一条经过北墙后继续向地下延伸，穿过旧厂区，通向地图边缘一座已拆除建筑；图纸上没有标建筑名称，只有编号B3-17。
- [P0024-P0028] 从七年前开始，所有新版管网图上都已经找不到这条管线；它不是被标记为停用，而是完全消失了，就像重新绘制图纸的人认为它从来没有存在过。
- [P0029-P0035] 八年前的检修记录中首次出现B3-17，记录为“北侧旧线异常，暂缓检修”；七个月后记录为“B3-17停止使用，相关设备封闭”；此后没有相关记录。
- [P0037-P0038] 通常地下管线停用需要留下断开位置、封堵方式和施工人员记录，但B3-17相关档案中这些都没有。
- [P0039] 纪燃用手机拍下旧管网图，准备把文件放回原处。
- [P0040-P0048] 纪燃在档案袋最里面发现一张泛黄的手写维修便签，上面写着“北线三次异响。”“仪表无异常。”“不要打开末端阀。”最后一句被黑笔重重划掉，下面仍能辨认出“螺栓已取下。”
- [P0049-P0052] 纪燃脚边的工具箱内侧小格中仍然放着那枚黑色螺栓；他没有碰它。
- [P0053-P0061] 档案室里安静几秒后，铁皮柜深处传来三下轻响，声音来自存放北三动力站旧档案的柜子后面，而不是从工具箱里来的。
- [P0062-P0065] 纪燃走到铁柜旁，看到铁柜紧贴墙壁，墙后没有设备；至少现在的建筑图上没有。
- [P0066-P0068] 铁柜与墙角之间积着厚灰，灰尘中有一道很窄的黑色痕迹，从墙缝一直延伸到柜子下面，像有什么东西曾经从里面渗出来。
- [P0069-P0070] 纪燃没有移动铁柜，只把手写便签折好，单独装进了文件袋。
- [P0071-P0073] B3-17所在的地下管线从北三动力站一直延伸到已经不存在的旧建筑；那只异常阀门正好装在这条管线进入地下之前的最后一个位置。
- [P0074-P0076] 纪燃意识到，七年前被“封闭”的也许从来就不是一条废弃管线；真正被封起来的，是管线另一头的东西。
