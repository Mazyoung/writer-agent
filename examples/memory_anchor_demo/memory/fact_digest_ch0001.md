# 第1章 事实摘要

### 确定的物品
- **黑色芯片（无标识）**：老周寄出的包裹内，后置于林默衬衫贴身口袋。常规读数设备检测显示存储空间为空，但有一个极低功耗的读数，频率稳定——芯片在主动发射定位信号。
- **纸条「林医生，帮我保管。别看。」**：包裹内，字迹潦草但有力，折了两折。背面照片地址为同一笔迹（推断为老周的字）。
- **半张旧照片**：人脸被刀片刮掉，只剩轮廓；背面用圆珠笔写着林默诊所的地址。
- **老周死亡证明**：周德海，男，68岁，退伍军人；死因「心血管衰竭」；死亡地点为住所；发现人为邻居。
- **老周病历档案**：四年，十七次就诊；心率、血压、神经接口反应指数均正常。
- **工作笔记本**：老周记录页右下角被撕掉（沿装订线，手法干净），被撕位置正好是首次就诊日期。
- **记忆伦理委员会公函**：红章，落款两天前，列入2047年第二轮常规检查范围，十个工作日内提交自查报告。
- **源记忆托管资格申请表副本**：受理日期一月九日，签名栏为「林默」，但非其笔迹。
- **老兵记忆扫描数据**：海马体浅层有标准协议批量删除痕迹；残影底层有军用标准删除协议变体的衰减轨迹；编码规则签名与五年前墨涅公司样本一致。

### 确定的角色状态
- **林默（34岁记忆修复师）**：位置为诊所；身体状态正常，但出现无意识的食指敲击桌面三下的动作（过去操作神经接口的节奏）；短期记忆异常（想不起老周首次就诊日期）；心理状态从职业性冷漠逐渐转为怀疑、警惕、偏执清明。
- **老周（周德海，68岁，已故）**：死亡状态确认；官方死因心血管衰竭，但与病历记录矛盾（心脏无问题）；紧急联系人号码已停机。
- **老兵（67岁，未具名）**：2042年边境冲突参战者；战争记忆被军方批量清理；经「老弟兄」推荐来访；首次会面，约下周做深度整合。
- **邮局工作人员（女声）**：墟层分局，记得寄件人为「年纪挺大，大概六七十，背有点驼」的老人，现金支付，无身份信息。
- **伦理委员会接线员（男声）**：解释检查为「政策调整」，提及表格副本。

### 确定的事件
1. 早上七点二十，林默收到退回邮件——寄给老周的术后护理指南被退回，附死亡证明（心血管衰竭）。
2. 林默翻出老周四年十七次就诊的病历档案，全部指标正常——发现矛盾。
3. 拨打老周紧急联系人电话——号码已停机。
4. 林默试图回忆老周首次就诊日期失败，打开工作笔记本发现记录页被撕掉。
5. 下午两点，无寄件人包裹送达（揽收网点为墟层邮局），内含黑色芯片、纸条、半张旧照片。
6. 芯片检测为空盘，但检测到低功耗稳定频率的发射信号；林默致电揽收网点，邮局人员回忆为老人现金寄件。
7. 照片背面有林默诊所地址，笔迹与纸条一致。林默将芯片放入衬衫贴身口袋，手掌在口袋外按了按确认。
8. 下午四点零七分，老兵到访。自述军方做过记忆清理（2042年边境冲突后），想找回被清掉的记忆。
9. 扫描中发现大片规整信号中断区（批量删除），执行碎片整合时发现军用标准删除协议变体的衰减轨迹——编码签名与五年前墨涅公司样本一致。林默标记后不动声色结束本次扫描，约老兵下周深度整合。
10. 下午五点四十分，拆开伦理委员会公函——三个月内第二次检查（上一次为去年十二月）。
11. 致电质询，接线员称「政策调整」。邮件附带一份「源记忆托管资格申请」表格副本——受理日期一月九日，签名「林默」但非林默笔迹。
12. 林默重新查验笔记本撕痕——沿装订线、无毛边，判断撕得很干净。芯片在台灯下查看后放回口袋。
13. 关灯锁门，出诊所后本应向左转回家——转身向右。
